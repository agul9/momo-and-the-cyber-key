# Momo and The Cyber Key
A p5.js exploration game about a post-climate-disaster future world where society has been rebuilt around environmental survival by having humans live inside an isolated, high-tech district.

**[Play here!](https://agul9.github.io/momo-and-the-cyber-key/)**

### My Role
Designed parts of the game art, such as the maps and characters, and implemented gameplay mechanics, including collision detection and screen transitions.

### Tech Stack
p5.js
